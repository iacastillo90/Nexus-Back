# 1. ✅ RESUMEN DE VALIDACIÓN TÉCNICA BACKEND

## 1.1 Estructura de Datos (JSONs Reales)

### Usuario Base
```json
{
  "id": "uuid-v4",
  "username": "neo",
  "email": "neo@matrix.com",
  "firstName": "Thomas",
  "lastName": "Anderson",
  "isActive": true,
  "isVerified": true,
  "echoEnabled": false,
  "echoPlan": "free",
  "createdAt": "2023-10-27T10:00:00.000Z",
  "updatedAt": "2023-10-27T10:00:00.000Z"
}
```
⚠️ **CRÍTICO**: NO incluye `karma`, `bio`, ni `avatar`. Estos vienen de endpoints separados.

### Post Completo
```json
{
  "id": "uuid-post",
  "content": "Hello Matrix",
  "mediaUrls": ["https://cdn.example.com/image.jpg"],
  "visibility": "PUBLIC",
  "sentiment": "positive",
  "emotionalTone": { "joy": 0.8, "sadness": 0.1 },
  "geolocation": { "type": "Point", "coordinates": [-73.98, 40.75] },
  "arMetadata": { "anchorType": "plane" },
  "userId": "uuid-author",
  "contentDna": "sha256-hash",
  "createdAt": "2024-01-15T10:00:00.000Z",
  "author": {
    "id": "uuid-author",
    "username": "neo"
  }
}
```

### Notificación
```json
{
  "id": "uuid-notif",
  "userId": "my-uuid",
  "recipientId": "my-uuid",
  "senderId": "other-uuid",
  "type": "like",
  "content": "Someone liked your post",
  "relatedId": null,
  "postId": "uuid-post",
  "read": false,
  "createdAt": "2024-01-15T10:00:00.000Z"
}
```

## 1.2 Decisiones Técnicas Confirmadas

| Aspecto | Decisión | Implicación Móvil |
|---------|----------|-------------------|
| **Paginación** | Offset/Limit (page + limit) | Usar `infinite_scroll_pagination` con números enteros |
| **Media Upload** | 2 pasos (Upload → URL → Create Post) | Implementar endpoint de upload o usar CDN directo |
| **Caché Writes** | POST devuelve objeto (201), DELETE devuelve vacío (204) | Agregar objeto a lista local en 201, eliminar por ID en 204 |
| **Mapas** | Backend agnóstico (MySQL ST_Distance) | Usar Mapbox por estilización cyberpunk |
| **Real-Time** | Socket.IO con Redis Adapter | Confiar en balanceo del backend |
| **Content DNA** | Backend-only (firmado en servidor) | Solo enviar contenido, no generar hash |
| **Karma/Vibes** | Endpoints separados de User | Hacer fetches paralelos o secuenciales |
| **Auth** | JWT simple (sin Refresh Token en MVP) | Implementar Refresh en Sprint 2 |
| **Streaming Chat** | NO implementado (respuesta completa) | Usar indicador "Escribiendo..." hasta recibir JSON |

## 3.2 Justificación de Tecnologías Clave

| Tecnología | Por qué es CRÍTICA para Nexus |
|------------|-------------------------------|
| **Riverpod 2.0** | Code generation elimina boilerplate. AutoDispose automático. Mejor testability que Provider o Bloc. Permite invalidación granular de estado. |
| **Isar** | 10x más rápido que Hive/SQLite. Queries complejas nativas. Soporte geolocalización. Perfecto para caché offline-first. |
| **Retrofit + Dio** | Type-safe API calls. Auto-generación reduce errores humanos. Interceptors para auth/logging. Retry logic built-in. |
| **Mapbox** | Único que permite estilización cyberpunk total. Better performance que Google Maps en zonas densas. Custom markers con WebGL. |
| **Talker** | Logs estructurados + UI de debug in-app. Ver todas las requests/errors en tiempo real. Crítico para debugging en producción. |
| **Flutter Animate** | Animaciones declarativas (menos código que AnimationController). 60fps garantizado. Perfect para micro-interacciones. |
| **Freezed** | Immutability automática. copyWith sin dolor. Union types para estados complejos. |
| **GoRouter** | Deep linking built-in. Type-safe routes. Redirection logic centralizada. |
